Bedienung

Die Anwendung zeigt drei unterschiedliche parametrisierte 3D-Flächen. Alle Flächen werden algorithmisch mit JavaScript und WebGL erzeugt.

  • Taste B: Zwischen den drei Flächen wechseln.
  • Taste L: Zwischen dem reinen Liniengitter und der farbigen Fläche mit Linien wechseln.

Alternativ können die beiden Buttons oberhalb verwendet werden.

Dokumentation der Flächen

1. Helikoid (Wendelfläche)

Das Helikoid ist eine spiralförmige Fläche, die sich um eine zentrale Achse windet.

Parametrisierung:

x(r,t) = r * cos(t) y(r,t) = 0.18 * t z(r,t) = r * sin(t)

Parameterbereiche:
-0.7 ≤ r ≤ 0.7
-π ≤ t ≤ π

Kolorierung: Blau-türkiser Farbverlauf mit hellem Liniengitter.

Quelle: 3D-Meier - Helicoid (3.20)

2. Möbiusband

Das Möbiusband ist ein ringförmiges Band mit einer halben Verdrehung. Es besitzt nur eine zusammenhängende Seite.

Parametrisierung:

R(u,v) = 0.6 + v * cos(u/2) x(u,v) = R(u,v) * cos(u) y(u,v) = R(u,v) * sin(u) z(u,v) = v * sin(u/2)

Parameterbereiche:
0 ≤ u ≤ 2π
-0.22 ≤ v ≤ 0.22

Kolorierung: Violett-rosa Farbverlauf mit hellem Liniengitter.

Quelle: 3D-Meier - Möbius Band (3.9)

3. Wellenblüte (Eigenkreation)

Die Wellenblüte ist eine selbst entwickelte parametrisierte Fläche. Sie kombiniert eine radiale Wölbung mit sieben periodischen Wellen, wodurch eine blütenartige 3D-Struktur entsteht.

Eigene Parametrisierung:

R(r,t) = 0.64*r*(1 + 0.22*r*cos(7*t)) x(r,t) = R(r,t)*cos(t + 0.3*r) y(r,t) = 0.36*(1 - r*r) + 0.18*r*r*cos(7*t + 0.3*r) - 0.14 z(r,t) = R(r,t)*sin(t + 0.3*r)

Parameterbereiche:
0 ≤ r ≤ 1
0 ≤ t ≤ 2π

Kolorierung: Radialer Farbverlauf von Goldgelb über Orange bis Pink mit dunklem Liniengitter.

Quelle: Eigene mathematische Parametrisierung, entwickelt durch Kombination trigonometrischer Funktionen und radialer Terme.

Quellen und technische Umsetzung

GVT-Skript:
Graphical Visualisation Technologies, Lerneinheit 8 - Kurven und Flächen (KUF).

Mathematische Formelsammlung:
3D-Meier - Parametrische Flächen und Körper

Technologien:
HTML5, CSS, JavaScript und WebGL.

Umsetzung:
Die Geometrien werden durch zwei verschachtelte Schleifen erzeugt. Die berechneten Vertices werden über Index-Buffer zu Liniensegmenten und Dreiecken verbunden. Die Darstellung und Kolorierung erfolgen mit WebGL-Shadern.

Die Flächen sind auf den sichtbaren Koordinatenbereich skaliert. Für die Darstellung wird eine feste Drehung verwendet.
