Rekursive Kugel

Verändere die Rekursionstiefe, um die Dreiecksunterteilung der Kugel zu untersuchen.

Tiefe: 2 | Dreiecke: 128

Rekursionstiefe 0 bis 5. Ausgangsmodell: Oktaeder mit 8 Dreiecken.

Steuerung

  • Pfeil links / rechts: Kamera um die Szene drehen
  • Pfeil hoch / runter: Kamerahöhe verändern
  • N: Kameraradius verkleinern
  • Shift + N: Kameraradius vergrößern
  • Plus-Button (+): Rekursionstiefe erhöhen
  • Minus-Button (−): Rekursionstiefe verringern
  • Checkbox: Dreiecksnetz ein- oder ausblenden

Beschreibung der Anwendung

Die Szene besteht aus einem Kegel, einem Torus und einer rekursiv erzeugten Kugel. Alle drei Objekte werden mit WebGL dargestellt.

Die Kamera bewegt sich auf einer Kreisbahn um die Y-Achse. Die horizontale Kameraposition wird mithilfe von Sinus und Kosinus berechnet. Über die Pfeiltasten kann die Kamera horizontal um die Szene gedreht sowie ihre Höhe unabhängig vom Kameraradius verändert werden.

Die Kamerahöhe ist im Bereich von -30 bis +30 einstellbar. Über die Tasten N und Shift + N lässt sich der horizontale Kameraradius verändern. Die View-Transformation erfolgt mithilfe der Funktion mat4.lookAt().

Damit die Objekte auch bei großen Kamerahöhen gut erkennbar bleiben, wird der Öffnungswinkel der perspektivischen Kamera automatisch an die Entfernung zum Szenenzentrum angepasst. Dadurch bleibt die Darstellungsgröße der Objekte bei einer Höhenänderung annähernd konstant.

Die rekursive Kugel basiert auf einem Oktaeder mit acht Dreiecksflächen. Bei jedem Rekursionsschritt wird jedes Dreieck in vier kleinere Dreiecke unterteilt. Die neu berechneten Mittelpunkte werden auf die Kugeloberfläche normiert.

Die Anzahl der Dreiecke ergibt sich aus: T(n) = 8 · 4n, wobei n die Rekursionstiefe bezeichnet.

Die Geometrien werden algorithmisch in JavaScript erzeugt. Es werden keine externen Bilder oder fertigen 3D-Modelle verwendet.
